  Ready to set gatto up?

  gatto is an AI assistant that lives in your terminal. Describe a job in plain words and it does
  the work itself: reading, writing and running things on your computer, showing you every step.

  The thinking happens on this machine too: the model is a file on your own disk, so your words
  and your files never have to leave it.

  This machine: 128 GB of memory shared with the graphics chip, a model can use about 88 GB of it.

  Setting up takes a few minutes:

    machine   what this computer can run
    engine    a copy of llama.cpp, fetched for it
    model     pick one from Hugging Face, or bring your own
    check     gatto proves it works
    done      start talking to gatto

  Inside, Tab moves between the parts of a screen, ❯ shows where the keys are.
